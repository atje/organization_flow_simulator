Explore how an organization’s team structure and process settings affect work in progress and lead times. The simulation runs in your browser; saved configurations are kept in this browser’s local storage.

Set up a simulation

  1. Use Team setup to add and remove teams, edit team names, and connect teams using Feeds into. Each team can have multiple process stages.
  2. Set each stage’s duration and work-in-progress (WIP) limit. A limit of 0 means there is no WIP limit. You can also set each team’s rework probability and rework duration.
  3. In Simulation setup, choose the number of work items, their arrival interval, process variation, and animation speed. Hover over a setting for more information.
  4. Optionally use Load/save configuration to save the current parameters and team setup, restore a saved configuration, or delete one.

Run and follow the simulation

Select Start simulation to begin. Use Pause and Resume to stop and continue, or Reset to clear the current run. Starting another simulation begins a new run with the selected settings.

Team flow view shows work moving through each team’s stages, including items queued at a stage, team handoffs, and completed output. When a downstream team receives work from multiple upstream teams, it waits until all of them have finished that work item.

The completed and in-process counts, average lead time, and 95th-percentile lead time remain visible as you move between sections. Stats view charts completed, in-process, queued, and waiting work by simulation day.

Enjoy exploring how different setups change the flow of work.
